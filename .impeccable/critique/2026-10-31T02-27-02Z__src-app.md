#### Priority Issues

**[P1] Brand-orange as UI text fails normal contrast (~3.39:1)**
- Why: `#ec5e27` on white is unsafe for body/link-sized text; `--accent` `#b54115` is safer (~5.63:1).
- Fix: Bright orange for fills/large display only; UI text/links use `--accent`/`--orange-strong`.
- Suggested: `/impeccable audit` then polish.

**[P1] Orange token drift + primary button ink flip**
- Why: `--orange-soft`/`pale` are gray/white; primary button ink goes black→white on hover.
- Fix: Clarify token roles; lock primary button to white ink on brand fill (including hover).
- Suggested: `/impeccable polish`.

**[P1] Mobile public nav hides Como funciona / Ranking / Começar**
- Why: Only Entrar remains ≤767px; Casey loses teaching paths.
- Fix: Keep one secondary path or minimal overflow; don’t bury both destinations.
- Suggested: `/impeccable adapt`.

**[P2] Auth emotional valley after landing peak**
- Why: Bare white column severs city/demo story at conversion.
- Fix: One restrained local cue (eyebrow/city line) without new cards.
- Suggested: `/impeccable layout` / quiet delight.

**[P2] /app chrome density**
- Why: FAB + dock + tabs + search + aside compete; mid-width sidebar icon-only.
- Fix: One primary create path; ensure accessible labels.
- Suggested: `/impeccable distill` + adapt.
